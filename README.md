# Farm Management App

WebView wrapper for the existing Masaallah Agro WordPress software.

## Build
1. Open this folder in Android Studio.
2. Let Gradle sync.
3. Select `app` and run on a device/emulator.
4. For an APK: Build → Build APK(s), or Generate Signed Bundle / APK for a release build.

## Website URL
The app opens:
https://masaallahagro.com

If your production URL differs, edit `homeUrl` in `MainActivity.kt`.
